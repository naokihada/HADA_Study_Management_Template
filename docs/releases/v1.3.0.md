# Release v1.3.0

HADA Study Management Template v1.3.0 is the migration-safe baseline for the
public Template and fictional Sample repositories.

## Included

- Candidate-first, three-way Template Upgrade preparation
- Version-carrier and public-artifact validation
- Required public operational files: `AGENTS.md` and `AI/README.md`
- Manifest-driven exclusion of SPEC, ReSPEC, AI workspaces, and private logs
- AI Reset structure restoration from the versioned repository structure
- Existing learning records, planning, calendar, photo, domain-pack, and import
  capabilities

Schema and data format remain `1.0.0`.

## Safety boundary

AI Reset is experimental and potentially destructive. Review the dry-run before
using `--apply`. User data, consent records, upgrade evidence, and sidecar
files must remain outside `AI/`.

Git commit, push, tag, and GitHub Release operations remain manual.

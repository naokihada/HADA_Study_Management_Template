# Pet Growth and Care

## Initial prompt

```text
ペットの成長とケア向けに設定。食事、散歩、遊び、しつけ、体重、体長、行動、通院、予防接種、日付写真を1年間記録する。
```

## One-year path

- Month 1: 基本情報、生活リズム、体重、食事を登録
- Month 3: 行動、散歩、しつけ、写真を日付単位で記録
- Month 6: 成長変化と健康イベントをレビュー
- Month 9: 季節変化、通院、予防接種、ケア計画を追加
- Month 12: 成長、生活、健康イベント、写真を総括

## Expansion prompt

```text
ペットの半年分の記録から、体重、食事、運動、行動の変化を整理する。健康について断定せず、異常に見える点は獣医師へ確認する質問としてまとめる。
```

# Daily Meal Planning

## Initial prompt

```text
毎日の献立記録向けに設定。朝昼夕の献立、レシピ、材料、買い物、費用、調理時間、残り物、写真、任意の栄養推定を管理する。
```

## One-year path

- Month 1: 1週間の献立と買い物を記録
- Month 3: 調理時間、費用、残り物、家族の反応をレビュー
- Month 6: 冷蔵庫の在庫、季節、作り置きを計画へ追加
- Month 9: 忙しい週、来客、行事、予算変更に対応
- Month 12: 年間の定番、費用、廃棄、改善点を総括

## Expansion prompt

```text
直近4週間の献立を分析し、費用、調理時間、残り物、家族の好みから翌週の献立案を作る。栄養値は推定と明記し、医療・食事療法の判断は行わない。
```

# Tetris 99 Improvement

## Initial prompt

```text
Tetris 99向けに設定。1年間で生存力と順位を改善するため、順位、生存時間、バッジ、攻撃、受ける圧力、トップアウト、イベントを管理する。
```

## One-year path

- Month 1: 順位、生存時間、バッジ、トップアウトを記録
- Month 3: 初期圧力、ターゲット選択、積みの崩れを分類
- Month 6: 中盤・終盤の生存課題を別Sprint化
- Month 9: イベントや特別ルールに合わせて目標を更新
- Month 12: 順位分布、安定性、イベント達成状況を総括

## Expansion prompt

```text
Tetris 99の直近30試合を初期圧力、中盤の積み、ターゲット選択、終盤の生存に分類し、順位に影響する課題を1つだけ次のSprintへ移す。
```

# Art Practical Examination

## Initial prompt

```text
美大実技試験向けに設定。デッサン、色彩構成、平面・立体構成、彫刻、面接、小論文、ポートフォリオを分け、制作時間、構図、形態、質感、色彩、空間、講評を記録する。
```

## One-year path

- Month 1: 志望校、専攻、試験方式、評価基準を整理
- Month 3: デッサンと構成課題を制作時間・講評付きで記録
- Month 6: 弱点観点を1〜3個に絞り、反復課題を作成
- Month 9: 模試、面接、小論文、ポートフォリオを追加
- Month 12: 作品群、講評、評価傾向、次年度課題を総括

## Expansion prompt

```text
美大実技の作品記録を構図、形態、比例、質感、調子、色彩、空間、観察、時間管理に分類する。大学公式基準、予備校意見、個人講評を分け、写真は日付単位で保存する。
```
## Beginner prompt kit

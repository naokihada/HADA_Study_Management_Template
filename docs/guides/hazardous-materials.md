# Hazardous Materials Qualifications

## Initial prompt

```text
危険物取扱者向けに設定。乙4、乙5、甲種を別variantとして扱い、法令、物理・化学、性質・消火、過去問、模試、申込、試験日、結果を管理する。
```

## One-year path

- Month 1: 類、受験資格、試験範囲、教材を確認
- Month 3: 分野別正答率と誤答理由を記録
- Month 6: 模試、時間配分、弱点Sprintを追加
- Month 9: 乙4から乙5または甲種への更新を検討
- Month 12: 試験結果、出典、次の資格計画を総括

## Expansion prompt

```text
危険物乙4の記録を分析し、法令、物理・化学、性質・消火の弱点を分ける。乙5または甲種へ進む場合は、公式の受験資格と試験日程を確認し、適用前に変更内容を表示する。
```

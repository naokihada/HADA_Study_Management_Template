# Dead or Alive 6 Improvement

## Initial prompt

```text
Dead or Alive 6向けに設定。1年間で対戦力を改善するため、キャラクター、ランク戦、ホールド、カウンター、壁際、リプレイ、練習課題、大会を管理する。ゲームバージョンと出典を保存する。
```

## One-year path

- Month 1: キャラクターと基本攻防、対戦結果を記録
- Month 3: ホールド、カウンター、壁際の失敗を分類
- Month 6: キャラクター別対策とリプレイレビューを追加
- Month 9: 大会前の防御・判断Sprintを実施
- Month 12: 勝率、守備課題、成長点を総括

## Expansion prompt

```text
Dead or Alive 6の敗因をホールド判断、カウンター、壁際、コンボ、防御選択に分類し、最も再発する課題を1つ選んで3回の練習セッションを作る。推測は明記する。
```
## Beginner prompt kit

# Fortnite Improvement

## Initial prompt

```text
Fortnite向けに設定。1年間で対戦力を改善するため、モード、降下地点、装備、撃破、順位、被撃破原因、建築、編集、エイム、終盤判断、シーズンとパッチを管理する。
```

## One-year path

- Month 1: モード、降下、順位、初動の失敗を記録
- Month 3: 建築・編集・エイムの個別練習を開始
- Month 6: 中盤の判断と終盤の位置取りをリプレイで確認
- Month 9: シーズン目標と大会準備をSprint化
- Month 12: 順位、撃破、継続課題、次シーズン計画を総括

## Expansion prompt

```text
Fortniteの直近30試合を初動、中盤、終盤、建築、編集、エイム、判断に分類し、順位に最も影響する課題を2つ選ぶ。シーズン、パッチ、使用モードを記録する。
```

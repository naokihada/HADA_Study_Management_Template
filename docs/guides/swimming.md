# Swimming Training

## Initial prompt

```text
水泳向けに設定。1年間で距離、タイム、ペース、泳法、ストローク、フォーム、疲労、回復、大会を管理する。練習量と技術課題を分ける。
```

## One-year path

- Month 1: 泳法、距離、タイム、疲労を記録
- Month 3: フォームとペースの課題を分類
- Month 6: インターバル、持久力、技術Sprintを分ける
- Month 9: 大会または自己ベスト向けの仕上げを行う
- Month 12: 距離、タイム、疲労、継続率、次年度目標を総括

## Expansion prompt

```text
水泳の直近12セッションを距離、タイム、泳法、フォーム、疲労に分類し、タイム向上を妨げる課題を1つ選ぶ。疲労や痛みがある場合は無理な練習案を出さず、専門家への確認事項として記録する。
```

# High School Entrance Examination

## Initial prompt

```text
高校受験向けに設定。最大3年間、複数志望校、5教科、定期試験、模試、学校説明会、出願、合格発表を管理する。学期をSprintとして扱い、偏差値と弱点を時系列で保存する。
```

## One-year path

- Month 1: 志望校、科目、現在の成績、教材を登録
- Month 3: 定期試験と模試を比較し、弱点Sprintを作成
- Month 6: 夏休み計画、学習時間、復習サイクルを追加
- Month 9: 志望校、学校説明会、出願準備を見直す
- Month 12: 偏差値、学習時間、改善科目、次年度目標を総括

## Expansion prompt

```text
高校受験の直近3回の模試と定期試験を比較し、偏差値、正答率、科目別の傾向を整理する。次のSprintの優先科目を2つまでにし、志望校変更案は確認前の候補として保存する。
```
## Beginner prompt kit

```text
今日の勉強を科目、内容、時間、できたこと、次にやることに分けて記録して。
```

```text
今週の記録から、来週の優先科目を2つ選びSprintを作って。
```

```text
この模試結果を科目別に整理し、事実と弱点の仮説を分けて。
```

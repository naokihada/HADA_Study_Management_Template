# Motorcycle Maintenance

バイクの趣味を、走行記録とメンテナンス履歴を組み合わせたライフワークとして管理します。

## Initial setup prompt

```text
バイクの趣味とメンテナンス用に設定。走行、距離、整備、部品、費用、車検、保険、次回整備、日付写真を記録し、1年後に維持費と整備履歴を総括する。
```

## One-year example

- Month 1: 車両情報、現在距離、整備履歴を登録
- Month 3: オイル、タイヤ、チェーンなどの状態を確認
- Month 6: ツーリング記録と費用をレビュー
- Month 9: 車検・保険・冬季保管を計画
- Month 12: 年間走行距離、費用、故障、次年度整備を総括

写真は`artifacts/<year>/`に日付接頭辞で保存します。写真と整備記録はIDで関連付けず、同じ日付の写真をグループとして表示します。
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日の走行を車両、距離、時間、天候、気づき、次回確認に分けて記録して。
```

```text
今日の整備を部品、作業、費用、工具、確認結果、次回整備に分けて記録して。
```

```text
この整備写真の見える状態と確認が必要な点を分けて。安全判断は専門家確認にして。
```

```text
走行距離と履歴から次回整備候補を作って。マニュアルを優先して。
```

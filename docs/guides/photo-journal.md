# Photo Journal

## Initial prompt

```text
写真日記向けに設定。日付写真、短いキャプション、出来事、観察、月間テーマ、振り返りを記録する。写真は記録の補助であり、写真がない日も有効な記録にする。
```

## One-year path

- Month 1: 日付写真と一言メモを保存
- Month 3: 場所、季節、出来事、気分を分類
- Month 6: 月間テーマと代表写真を選ぶ
- Month 9: AIによる説明候補を確認・修正して保存
- Month 12: 年間アルバム用の文章とテーマを総括

## Expansion prompt

```text
写真を日付ごとに整理し、キャプション候補と月間テーマを作る。人物、場所、植物、食べ物の名前はAIの推測を確定せず、ユーザーが確認した内容だけを事実として保存する。
```
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日の写真を撮影日、見える事実、一言キャプション、思い出、確認事項に分けて記録して。
```

```text
今月の写真からテーマを3つ提案して。写真にない内容は推測と明示して。
```

```text
この写真の説明文を短文、SNS用、日記用の3種類で作って。人物や場所は断定しないで。
```

```text
年間写真を月ごとに整理し代表写真を選ぶ基準を作って。
```

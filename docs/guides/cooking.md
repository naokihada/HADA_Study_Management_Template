# Cooking and Recipe Practice

## Initial prompt

```text
料理とレシピ向けに設定。レシピの出典、材料、分量、調理時間、写真、味の感想、改善点、費用を記録し、1年間で再現性の高い料理を増やす。
```

## One-year path

- Month 1: よく作る料理、レシピ、材料、調理時間を登録
- Month 3: 味、火加減、分量、盛り付けの失敗を分類
- Month 6: 季節料理、焼き菓子、作り置きなどを追加
- Month 9: 家族の好み、費用、買い物、残り物利用を計画
- Month 12: 再現性、費用、人気料理、次年度テーマを総括

## Expansion prompt

```text
料理記録を分析し、味、食感、火加減、分量、調理時間、費用に分類する。次の3回は変更する条件を1つに絞り、レシピ出典と写真の日付を保存する。
```

画像解析による材料・栄養推定は参考情報に限定し、食品表示や計量を優先します。


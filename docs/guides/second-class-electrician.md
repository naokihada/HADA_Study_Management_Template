# Second-Class Electrician

## Initial prompt

```text
第2種電気工事士向けに設定。学科と技能を分け、1年間の学習時間、過去問、技能課題、作業時間、欠陥、改善点、試験日程、練習写真を管理する。
```

## One-year path

- Month 1: 学科範囲、技能課題、試験日程、教材を登録
- Month 3: 過去問の正答率と欠陥パターンを記録
- Month 6: 技能課題の作業時間と写真を日付単位で保存
- Month 9: 本番時間での反復、持ち物、会場、移動を確認
- Month 12: 学科・技能の結果と次の資格目標を総括

## Expansion prompt

```text
第2種電気工事士の技能練習を分析し、作業時間、欠陥、手順ミス、安全確認に分類する。次の3セッションは最も多い欠陥だけを改善し、写真は日付グループで保存する。
```
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日の学科勉強を分野、問題数、正答数、誤答、次の復習に分けて記録して。
```

```text
今日の技能練習を課題、作業時間、欠陥、原因、次回の改善に分けて記録して。
```

```text
この技能写真について、見える事実と欠陥の可能性を分けて。
```

```text
学科と技能の進み具合から、次の1週間の配分案を作って。安全事項は確認事項にして。
```

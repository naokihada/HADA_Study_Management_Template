# Creative Idea Log

## Initial prompt

```text
漫画や創作の本格的な連載管理ではなく、アイデア帳として設定。タイトル、キャラクター、世界観、場面、参考資料、気づき、次の検討事項を記録する。
```

## One-year path

- Month 1: アイデア、参考資料、未整理メモを保存
- Month 3: テーマ、キャラクター、場面を分類
- Month 6: 再利用できる設定と没案を整理
- Month 9: 短編化できる案を選び、試作課題を作成
- Month 12: アイデアの成長と次年度の制作候補を総括

## Boundary

ページ工程、入稿、編集者連絡、権利管理を含む本格的な連載管理は別プロジェクト候補とする。

## Beginner prompt kit

```text
思いついた創作案を、タイトル、着想、登場人物、舞台、場面、次の検討に分けて保存して。
```

```text
今月のアイデアをテーマ、再利用できる設定、保留、没案に分類して。元のメモは消さないで。
```

```text
このアイデアを短編にする場合の最小構成を候補として作って。勝手に設定を確定しないで。
```

```text
アイデア帳から本格制作へ進める候補を選び、必要な確認事項と別プロジェクト化の境界を示して。
```

# Jogging Training

## Initial prompt

```text
ジョギング向けに設定。1年間で距離、時間、ペース、心拍、疲労、痛み、コース、休養、大会を記録し、継続と安全を優先する。
```

## One-year path

- Month 1: 距離、時間、ペース、体調を記録
- Month 3: 疲労、痛み、継続率、ペース停滞をレビュー
- Month 6: イージー、ロング、インターバルをSprint化
- Month 9: 大会や目標距離に向けて計画を調整
- Month 12: 年間距離、自己ベスト、休養、次年度目標を総括

## Expansion prompt

```text
ジョギングの直近3か月を分析し、距離、ペース、疲労、痛み、休養の関係を整理する。負荷を増やす提案は慎重にし、痛みがある場合は医療・専門家への相談候補として扱う。
```
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日のジョギングを距離、時間、ペース、体調、疲労、痛み、次の注意に分けて記録して。
```

```text
直近1か月の距離、ペース、休養、疲労の関係を整理して。
```

```text
次の7日間を無理なく続ける計画にして。痛みがあれば休養を優先して。
```

```text
自己ベストだけでなく継続率と体調を含めた月次レビューを作って。
```

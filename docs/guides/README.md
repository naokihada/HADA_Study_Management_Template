## Usage levels

- `Core Supported`: 共通構造と基本検証の対象
- `Domain-pack Supported`: 指標や課題をdomain packで追加可能
- `Usage Guide Supported`: 応用方法を説明するガイド
- `Future Extension Candidate`: 専用コンテンツを今後検討する対象

## One-year operation pattern

各用途は、初期設定、最初の7日間、1か月、3か月、6か月、12か月の順で拡張できます。途中で別用途へ変える場合は、domain lockの警告と履歴保存を確認してください。

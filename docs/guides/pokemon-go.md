# Pokémon GO Long-term Record

## Initial prompt

```text
Pokémon GO向けに設定。1年間でコレクション、レイド、PvP、歩行、イベントを管理する。期限付きイベント、シーズン、確認日、必要リソースを記録する。
```

## One-year path

- Month 1: コレクション、歩行、レイド、PvPの目標を分ける
- Month 3: リソース不足とイベント優先順位をレビュー
- Month 6: PvPまたはレイドの重点目標を選択
- Month 9: 期限付きイベントとシーズン変更を計画
- Month 12: コレクション、距離、戦績、費用、次年度目標を総括

## Expansion prompt

```text
Pokémon GOの次のイベントに向け、期限、現在の進捗、必要リソース、必須目標、任意目標を分けた計画を作る。イベント情報のURLと確認日を保存する。
```
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日のPokémon GOを捕獲、レイド、PvP、歩行、イベント、使ったリソースに分けて記録して。
```

```text

```

```text
次のイベントに向け、無理なく達成する優先順位と確認事項を作って。
```

# First-Class Electrician

## Initial prompt

```text
第1種電気工事士向けに設定。学科と技能を分け、1年間の試験対策、技能課題、作業時間、欠陥、法令、安全、試験日程、関連する第2種の履歴を管理する。
```

## One-year path

- Month 1: 第2種から引き継ぐ知識と第1種固有範囲を分ける
- Month 3: 学科分野と過去問の弱点を評価
- Month 6: 技能課題、作業時間、欠陥、写真を追加
- Month 9: 本番形式、会場、持ち物、移動を確認
- Month 12: 合格結果と次の技能目標を総括

## Expansion prompt

```text
第2種電気工事士の履歴から第1種向け計画へアップグレードする。共通記録だけを候補として引き継ぎ、第1種固有の試験範囲と日程は公式情報を確認して別設定にする。
```
## Beginner prompt kit

# Study and Exam Guides

## 高校受験

```text
高校受験向けに設定。最大3年間、複数志望校、定期試験、模試、学校説明会、出願、合格発表を管理する。学期を複数Sprintとして扱い、偏差値推移は時系列データとして保存する。
```

1年目は基礎、2年目は弱点補強、3年目は模試・出願・本番対策として拡張します。

## 大学受験

```text
大学受験向けに設定。大学、学部、学科、選抜方式を複数管理し、共通テスト、個別試験、面接、小論文、出願期限、入学手続期限を分けて記録する。
```

高校受験からの継続は、別プロジェクト作成または確認付きアップグレードとして扱います。

## 資格・技能試験

```text
第1種電気工事士向けに設定。学科と技能を分け、試験日程、技能課題、作業時間、欠陥、改善点を管理する。第2種の関連履歴を引き継ぐ範囲を確認してから適用する。
```

危険物乙4から乙5・甲種への更新も、関連domainの確認付きアップグレードとして扱います。

## 美大実技

```text
美大実技試験向けに設定。デッサン、色彩構成、平面・立体構成、面接、小論文、ポートフォリオを管理する。大学公式基準、予備校の指導観点、個別講評を別の出典レイヤーで保存する。
```

制作写真は任意の補助データであり、通常の学習記録を必須にしません。

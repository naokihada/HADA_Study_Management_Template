# Anime Diary

## Initial prompt

```text
アニメ感想記録向けに設定。作品、話数、視聴日、一言コメント、感想、好きな場面、テーマ、評価、視聴中断理由を記録し、月ごとに振り返る。
```

## One-year path

- Month 1: 視聴作品と一言コメントを毎回記録
- Month 3: 好きなテーマ、演出、キャラクターを分類
- Month 6: シーズンごとの感想と未完了作品をレビュー
- Month 9: 年間ベスト、再視聴候補、創作への影響を整理
- Month 12: 年間視聴記録と自分の好みの変化を総括

## Expansion prompt

```text
アニメの短い感想を消さずに、テーマ、演出、キャラクター、感情の変化に分類し、月間まとめを作る。ネタバレ範囲を明示し、外部情報と自分の感想を分ける。
```
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日見た作品と話数を一言コメント、好きな場面、感情、次に見るかに分けて記録して。
```

```text
今月の感想から、テーマと自分の好みを整理して。原文は消さないで。
```

```text
この感想をネタバレなしで短くまとめて。自分の感想と外部情報を分けて。
```

# Tetris Improvement

## Initial prompt

```text
一般的なTetris向けに設定。1年間でスコア、速度、積み方、安定性を改善するため、モード、スコア、ライン、時間、トップアウト、練習課題、自己ベストを管理する。
```

## One-year path

- Month 1: ルール、スコア、時間、トップアウトを記録
- Month 3: 積み方、穴、判断速度などの失敗を分類
- Month 6: Sprint、スタッキング、リカバリーを別課題化
- Month 9: 競技ルールや自己ベストへの準備を追加
- Month 12: スコア、速度、安定性、次年度課題を総括

## Expansion prompt

```text
Tetrisの直近20セッションをスコア、速度、トップアウト、穴、判断ミスに分類する。速度を上げる前に、最も再発する安定性課題を1つ選ぶ。
```
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日のTetrisをモード、スコア、ライン、時間、トップアウト、気づきに分けて記録して。
```

```text
直近20回から穴、積み、判断速度、トップアウトの傾向を整理して。
```

```text
次の1週間は速度と安定性のどちらを優先するか、記録を根拠に提案して。
```

```text
自己ベストだけでなく安定して続けられた回数を含めてレビューして。
```

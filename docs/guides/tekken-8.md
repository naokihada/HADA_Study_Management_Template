# Tekken 8 Improvement

## Initial prompt

```text
Tekken 8向けに設定。1年間で対戦力を改善するため、ランク戦、リプレイ、確定反撃、コンボ、苦手キャラクター、練習課題、大会を管理する。ゲームバージョン、パッチ、出典を保存する。
```

## One-year path

- Month 1: キャラクター、基本技、ランク戦、入力課題を記録
- Month 3: 直近30試合の敗因を分類し、確定反撃と防御課題を優先
- Month 6: キャラクター対策、リプレイレビュー、コンボ成功率を追加
- Month 9: 大会・オンラインイベントの仕上げSprintを作成
- Month 12: ランク、勝率、課題達成率、次年度目標を総括

## Expansion prompt

```text
Tekken 8の直近30試合から繰り返し発生する敗因を3つ以内に分類し、次の7日間の練習課題に変換する。事実、推測、外部攻略情報を分け、パッチ番号と確認日を付ける。
```
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

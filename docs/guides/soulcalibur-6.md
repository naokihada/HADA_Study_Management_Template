# Soulcalibur VI Improvement

Soulcalibur VIを1年間かけて上達するための旗艦使用例です。勝敗だけでなく、練習課題、敗因、リプレイ、キャラクター対策、イベント準備を記録します。

## Initial setup prompt

```text
Soulcalibur VI向けに設定。初心者が1年間で対戦力を改善できるように、キャラクター選択、ランク戦、トレーニングモード、敗因レビュー、キャラクター対策、大会準備を管理する。ゲームの現行情報を確認した場合は、出典、確認日、ゲームバージョンを付ける。
```

## First year example

- Week 1: 使用キャラクター、操作、基本技、目標を決める
- Month 1: ランク戦とトレーニング課題を記録する
- Month 3: 直近30試合の敗因を3つ以内に分類する
- Month 6: 苦手キャラクター対策とリプレイレビューを追加する
- Month 9: 大会・オンラインイベント向けの仕上げを行う
- Month 12: 勝敗、課題達成率、練習内容、次年度目標を総括する

## Possible expansions

- 確定反撃、コンボ、投げ抜け、起き攻め、リングアウト対策
- キャラクター別の課題と練習メニュー
- リプレイで見つけた繰り返しミス
- パッチ後の技・戦術の再確認
- 大会前のスプリントと特別イベント
- 複数キャラクターの比較

## Diagnostic prompt

```text
Soulcalibur VIの直近30試合を分析。勝敗だけでなく、繰り返している敗因を3つ以内に分類し、次の7日間のトレーニング課題へ変換する。記録上の事実、推測、ユーザーが確認すべき攻略情報を分ける。
```

## Data boundary

攻略情報は、ゲームバージョン、パッチ、出典、確認日を保存します。AIの提案は確定攻略情報ではなく、`review`に保存する練習候補です。
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日のSoulcalibur VIをキャラクター、対戦数、勝敗、気づき、次の練習に分けて記録して。
```

```text
直近30試合の確定反撃、コンボ、リングアウト、起き攻め、守備の課題を3つ以内に分類して。
```

```text
次の7日間の練習を1課題に絞り、比較できる指標も決めて。
```

```text
リプレイの事実、原因の仮説、外部攻略情報、次の行動を分けて.
```

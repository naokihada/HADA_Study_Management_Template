# Mobile Photo Workflow

ChatGPTのiOS・Androidアプリでは、画像を会話へ追加し、写真・ファイルを選択できます。Plus専用とは限らず、利用可能範囲や上限はアカウント・プラン・時期によって異なります。[OpenAI公式FAQ](https://help.openai.com/en/articles/8400551-image-inputs-for-chatgpt-faq)

## Current template boundary

現在のHADA Study Management TemplateはローカルGitファイルを保存先とするため、ChatGPTモバイルアプリがリポジトリの`artifacts/<year>/`へ直接保存する機能はありません。

現時点の安全な手順は次です。

1. モバイルアプリで写真を撮影または添付する
2. ChatGPTへ解析・整理・推定を依頼する
3. 出力内容をユーザーが確認する
4. 写真を手動でローカルの`artifacts/<year>/`へコピーする
5. 必要なら日付接頭辞のASCIIファイル名へ変更する

## Example prompts

```text
この料理写真から、見えている料理、推定材料、推定量、カロリー、タンパク質量を分けて整理して。画像だけでは不確かな項目を明示し、医療や食事療法の判断はしないで。確認後に献立記録用のMarkdownを作って。
```

```text
この草花写真から同定候補を3つまで出して。確信度、識別根拠、不足している観察情報、確認用の出典候補を分けて。断定はしないで。
```

```text
この写真を日付単位の写真日記に整理して。事実として見える内容、推測、ユーザーが確認すべき項目を分け、ASCIIファイル名候補も出して。
```

画像解析の結果は推定・補助情報です。写真だけでカロリー、栄養、植物種、健康状態などを正確に確定できるとは限りません。

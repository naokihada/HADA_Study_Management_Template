# General Prompt Catalog

このカタログは、特定の試験・ゲーム・趣味を初期設定するためのものではありません。どの用途でも使える、記録・計画・レビュー・安全確認の一般プロンプトだけを掲載します。用途固有の設定は、それぞれの個別ガイドを使ってください。

## Daily records

```text
昨日の記録を整理してください。事実だけを日付、内容、時間、結果、気づきに分け、推測は別欄にしてください。
```

```text
今日の記録をテンプレートに沿って作成してください。情報が足りない項目は空欄にし、推測で埋めないでください。
```

```text
未整理のメモを、既存データを削除せずに日付順へ整理してください。変更した箇所を最後に一覧で示してください。
```

## Weekly and monthly review

```text
過去1週間の記録をまとめてください。実施量、未完了、うまくいったこと、問題、次週に試すことを分けてください。
```

```text
先月の記録を要約してください。継続できた行動、停滞した項目、変化した数値、判断保留の事項を分けてください。
```

```text
過去4週間の傾向を確認してください。データに根拠がある傾向と、まだ件数不足で判断できないことを明確にしてください。
```

## Planning and JIRA-style progress

```text
来週のプランを作ってください。目標をEpic、具体的な作業をIssue、実行単位をTaskとして整理し、優先度と期限を付けてください。
```

```text
次のSprintの計画を作ってください。前Sprintの未完了Issueを確認し、無理のない件数だけを選び、完了条件を明記してください。
```

```text
現在のIssue一覧を確認し、Blocked、In Progress、Ready、Doneに分類してください。分類根拠と次の行動を1行ずつ示してください。
```

```text
期限と試験日を優先して、今週の作業順を並べ替えてください。変更前後、理由、確認が必要な日程を示してください。
```

## Safe updates and extensions

```text
既存データを削除・上書きせずに、新しい分類項目を追加できる案を作ってください。互換性、移行方法、確認が必要な点を示してください。
```

```text
現在のドメイン設定に別の用途を追加したいです。互換性を確認し、互換、確認付き互換、非互換の3分類で警告してください。強制変更は実行せず、確認を待ってください。
```

```text
この変更が既存の記録、計画、評価、写真ファイルに与える影響を調べてください。影響が不明なものはUNKNOWNと記録してください。
```

## Evidence and uncertainty

```text
このまとめを、事実、AIによる整理、推測、未確認事項に分けてください。推測を事実として書かないでください。
```

```text
日程や制度に関する情報を確認してください。公式情報を優先し、出典URL、確認日、対象地域・年度を付けてください。
```

```text
この提案の前提条件、期待できること、期待できないこと、専門家や公式情報への確認が必要なことを分けてください。
```

## Photos and AI boundary

```text
同じ日付の写真だけをグループとして一覧化してください。写真と記録を意味的に関連付けず、ファイル名と日付だけを扱ってください。
```

```text
写真を見て分かることと分からないことを分けてください。不鮮明な部分や健康・安全に関わる判断は推測せず、確認事項にしてください。
```

```text
ユーザーデータをAIフォルダへ保存しないでください。記録はdata、plans、records、artifactsへ、AIの一時作業物はAI/working、AI/cache、AI/reportsへ分離してください。
```

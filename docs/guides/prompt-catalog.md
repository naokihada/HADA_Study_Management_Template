# Prompt Catalog

以下は、初期設定または途中の拡張に使う短いプロンプト例です。適用前に、変更対象、既存データへの影響、出典、確認事項を表示するよう依頼してください。

## Fighting games

```text
Tekken 8向けに設定。ランク戦、リプレイレビュー、確定反撃、コンボ、苦手キャラクター対策を管理し、パッチ番号を記録する。
```

```text
Dead or Alive 6向けに設定。キャラクター別の技術課題、読み合い、ホールド、壁際の失敗、対戦結果を記録する。3か月後に苦手状況を再評価する。
```

```text
Pokkén Tournament向けに設定。フェイズ管理、キャラクター別練習、対戦結果、リプレイの気づき、大会準備を1年間追跡する。
```

## Other games

```text
Fortnite向けに設定。モード、降下地点、武器、撃破、順位、被撃破原因、建築・編集・エイム、シーズン情報を記録する。週ごとに改善課題を2つまで作る。
```

```text
Tetris系の上達記録として設定。Tetris、Tetris 99、Puyo Puyo Tetrisを別variantとして扱い、スコア、順位、ミスの種類、練習内容を比較できるようにする。
```

```text
Pokémon GOの長期記録として設定。捕獲、レイド、イベント、コレクション、PvP、歩行距離、期限付き目標を管理する。ゲーム内イベントの日付と確認日を保存する。
```

## Exams and study

```text
高校受験向けに設定。最大3年間、複数志望校、定期試験、模試、学校説明会、出願、合格発表を管理する。学期を複数Sprintとして扱い、偏差値推移は時系列データとして保存する。
```

```text
大学受験向けに設定。大学、学部、学科、選抜方式を複数管理し、共通テスト、個別試験、面接、小論文、出願期限、入学手続期限を分けて記録する。
```

```text
第1種電気工事士向けに設定。学科と技能を分け、試験日程、技能課題、作業時間、欠陥、改善点を管理する。第2種の関連履歴を引き継ぐ範囲を確認してから適用する。
```

```text
美大実技試験向けに設定。デッサン、色彩構成、平面・立体構成、面接、小論文、ポートフォリオを管理する。大学公式基準、予備校の指導観点、個別講評を別の出典レイヤーで保存する。
```

## Activities and research

```text
ジョギング向けに設定。距離、時間、ペース、疲労、痛み、コース、目標レースを記録し、月ごとに負荷と継続状況をレビューする。
```

```text
水泳向けに設定。泳法、距離、タイム、セット、フォーム、疲労度を記録し、4週間ごとに練習内容を見直す。
```

```text
夏休みの自由研究向けに設定。研究課題、仮説、観察、実験、結果、考察、写真、提出期限を管理する。前半は記録を優先し、後半にレポートへ整理する。
```

```text
バイクの趣味とメンテナンス用に設定。走行、距離、整備、部品、費用、車検、保険、次回整備、日付写真を記録し、1年後に維持費と整備履歴を総括する。
```

```text
漫画の本格制作ではなくアイデア帳として設定。タイトル案、キャラクター、世界観、場面、参考資料、気づきを記録する。連載工程や入稿管理は別プロジェクト候補として扱う。
```

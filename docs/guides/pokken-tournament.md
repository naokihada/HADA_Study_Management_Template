# Pokkén Tournament Improvement

## Initial prompt

```text
Pokkén Tournament向けに設定。1年間で対戦力を改善するため、キャラクター、フィールドフェイズ、デュエルフェイズ、サポート、リプレイ、対戦結果、大会を管理する。
```

## One-year path

- Month 1: 使用キャラクター、基本操作、フェイズごとの目標を記録
- Month 3: フェイズ移行とサポート選択の失敗を分類
- Month 6: キャラクター対策とリプレイレビューを追加
- Month 9: 大会・イベント向けに限定した練習Sprintを作成
- Month 12: 勝率、フェイズ別課題、次年度目標を総括

## Expansion prompt

```text
Pokkén Tournamentの直近20試合をフェイズ、サポート選択、起点作り、終盤判断に分類し、次のSprintでは課題を2つに限定する。対戦記録と推測を分ける。
```
## Beginner prompt kit

今日の対戦をキャラクター、フェイズ、結果、成功、失敗、次の課題に分けて記録して。

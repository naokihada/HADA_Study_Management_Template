# University Entrance Examination

## Initial prompt

```text
大学受験向けに設定。大学、学部、学科、選抜方式を複数管理し、共通テスト、個別試験、面接、小論文、実技、出願、合格発表、入学手続を正確に記録する。
```

## One-year path

- Month 1: 志望先、方式、必要科目、提出書類を整理
- Month 3: 模試、過去問、科目別弱点を評価
- Month 6: 夏季計画、志望順位、学習配分を更新
- Month 9: 出願、面接、小論文、実技をSprint化
- Month 12: 試験結果、手続期限、次の進路判断を総括

## Expansion prompt

```text
大学受験の志望先を大学、学部、学科、方式ごとに整理し、試験日、出願期限、合格発表、入学手続を確認する。公式情報を優先し、URLと確認日を保存する。
```

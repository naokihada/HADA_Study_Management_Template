# Nature Walk and Plant Observation

## Initial prompt

```text
散歩と草花観察向けに設定。散歩時間、距離、場所、草花の写真、観察メモ、季節、同定候補、確信度を1年間記録する。
```

## One-year path

- Month 1: 散歩ルートと観察対象を記録
- Month 3: 写真、開花、天候、季節の変化を分類
- Month 6: 同じ場所の定点観察を追加
- Month 9: AIや図鑑による同定候補を出典付きで保存
- Month 12: 季節変化、歩行習慣、観察テーマを総括

## Expansion prompt

```text
草花写真を観察メモとして整理し、同定候補、特徴、撮影日、場所、確信度を保存する。AIの同定は候補にとどめ、断定せず、確認に使った出典を記録する。
```
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日の散歩を時間、距離、場所、天候、草花、気づきに分けて記録して。
```

```text
この草花写真から同定候補を3つまで出して。特徴、不足情報、確信度、出典候補を分けて。
```

```text
同じルートの3か月分から季節変化と観察数を整理して。
```

```text
次の散歩で確認する観察項目を作って。位置情報は公開しない前提にして。
```

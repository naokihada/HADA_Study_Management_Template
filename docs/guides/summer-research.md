# Summer Research

夏休みの自由研究は、短期間の研究プロジェクトとして管理できます。

```text
Question -> Hypothesis -> Observation/Experiment -> Result -> Discussion -> Report
```

## Initial setup prompt

```text
夏休みの自由研究として設定。研究課題、仮説、観察、実験、結果、考察、写真、提出期限を管理する。前半は記録を優先し、後半にレポートへ整理する。
```

## One-year-compatible extension

短期研究後も、次の学期・次年度の継続研究へ拡張できます。

- 同じテーマの追跡観察
- 条件を変えた再実験
- 複数の研究テーマ比較
- 発表会や提出期限
- 研究ノートから最終レポートへの整理
- 出典と参考資料の管理
## Beginner prompt kit

AIに慣れていない人向けの、そのままコピーできる実用プロンプトです。日付、対象、結果を分かる範囲で追加してください。

```text
今日の自由研究を観察・実験、条件、結果、気づき、次の確認に分けて記録して。
```

```text
記録から事実、仮説、未調査事項を分けて。
```

```text
次の7日間の観察・実験計画を作って。記録にない結果は作らないで。
```

```text
最終レポートの構成案を作って。不明点を明示して。
```

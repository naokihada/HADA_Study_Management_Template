# 大学受験 domain pack

This configuration is a structural v1 example for university entrance
management. It supports multiple universities, faculties, departments,
selection methods, common-test subjects, individual exams, interviews,
essays, practical exams, application dates, examination dates, and result
dates. It is not the public Sample 1; that sample remains second-class
electrician. A future high-school sample is Sample 2.
